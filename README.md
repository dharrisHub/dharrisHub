An AI saying the work is finished and everything passes is a claim, not a fact. That gap is what I
work on. Big customers never asked whether my team worked hard, they asked us to prove the release
was safe, so we built proof: release health gates, SLOs, error budgets, a secure SDLC. Agents need
the same treatment and they need more of it, because they are fluent enough to be convincing when
they are wrong.

Everything below is built at **[EvolvLabs, LLC](https://evolvlabs.ai)**, where I am the founder and
the entire engineering department.

## What I'm building

**[Exolvra](https://exolvra.ai)** — a self-hosted operations platform that gives AI agents a project
board instead of a chat box. A manager agent decomposes the goal, specialist agents do the work, and
twenty-one guardrails validate every turn and re-drive the agent until the work passes. Runs on your
own infrastructure. In development, waitlist open.

**[DaycareLogix](https://www.daycarelogix.com)** — management software for childcare and adult day

## Open source

**[Exolvra Genesis](https://github.com/Evolvlabsai/Exolvra-Genesis)** · [`npm i -g exolvra-genesis`](https://www.npmjs.com/package/exolvra-genesis)

An adversarial build loop. A lead agent pins a hard quality bar — an artifact or a number, never an
adjective — builders iterate, and a fresh, blind critic compares the real output against that bar
without ever seeing the conversation that produced it. A tie counts as a loss. The run ends only
after two wins in a row. Ships as a Claude Code plugin and a Node CLI from one source of truth, so
the two cannot drift.

**[Competitive Research Skill](https://github.com/Evolvlabsai/Competitive-Research-Skill)**

Points itself at a codebase, works out what the product actually is, researches the competition, and
returns a ranked, evidence-backed list of what is missing — scored with Jobs-to-be-Done, Kano, and
RICE, and deduped against previous weeks so it stops repeating itself.
